title: Slow or missing mobile data
---
For slow or missing data, ask the customer to check for a current outage in their
region first. If there is none, suggest restarting the device, toggling airplane
mode for ten seconds, confirming mobile data is enabled and, if roaming, that
roaming is switched on. If the problem continues, open a network ticket so the
field team can investigate.
